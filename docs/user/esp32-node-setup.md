# AtomS3 LiteをOMK Nodeとしてセットアップする

AtomS3 Liteは市販のハードウェアです。OMK用ファームウェアと設定を書き込むと、センサ接続や通信の中継を担う「OMK Node」になります。このページでは、[組み立てたSEN66 Node](sen66-node-assembly.md)をGatewayへUSB接続し、Dashboardから設定・登録して計測を始めます。

新品・未セットアップのAtomS3 Liteは、以下の順に進めてください。追加の[中継専用Node](#中継専用nodeを追加する)や、[既存Nodeの再設定](#既存nodeを再セットアップする)は、このページ後半で説明します。

## この手順の前に

- [Gatewayセットアップ](gateway-setup.md)を完了し、OMK APとBLE機能が動作し、Dashboardを使える状態にしておきます。
- SEN66、接続基板、AtomS3 Liteを[SEN66 Nodeの組み立て](sen66-node-assembly.md)のとおり配線しておきます。**ケースの蓋はまだ固定しません。**
- データ通信に対応したUSBケーブルと、設置場所でNodeへ給電するUSB電源を用意します。

## 1. GatewayへUSB接続する

SEN66を配線したAtomS3 LiteのUSBケーブルを、**GatewayのUSB端子**へ接続します。このUSB接続は、給電と初回設定の両方に使います。取り違えを防ぐため、ほかのAtomS3 Liteや同種の開発ボードは、セットアップ中だけGatewayのUSBから取り外してください。

## 2. Dashboardからセットアップする

1. Touch Display 2のDashboardで、右上の歯車から「管理メニュー → 機器管理」へ進みます。
2. 「接続: USB接続」と表示されたOMK Nodeのカードを見ます。新品・未セットアップでは「USB接続されたNode候補」と「OMK Nodeをセットアップ」が表示されます。既存のOMK Nodeで「OMK Nodeを再セットアップ」が表示されたら、[既存Nodeの再設定](#既存nodeを再セットアップする)へ進んでください。
3. GatewayのUSBに接続した実物が**未セットアップのAtomS3 Lite**であることを確かめ、「未セットアップのAtomS3 Liteであることを確認しました」の行をタップしてチェックを入れます。初回設定を途中から再開する場合、この確認欄は表示されないことがあります。
4. 「OMK Nodeをセットアップ」を押します。Gatewayに用意されたファームウェアの書き込みと、OMK APへ接続するためのWi-Fi設定が自動で行われます。
5. **USB接続と給電を維持したまま、「セットアップ完了」と表示されるまで待ちます。**

「セットアップ完了」を確認したら、USBを接続したまま次のSEN66登録へ進みます。

「セットアップ失敗」と表示された場合やNodeが見つからない場合は、[Nodeセットアップのトラブルシューティング](troubleshooting.md#nodeセットアップを診断する)を参照してください。

## 3. SEN66を確認して登録する

Logical IDは、Nodeに接続したSEN66を区別する名前で、Dashboardや計測データで使います。ファームウェアのセットアップとは別に、この登録が必要です。

1. 「機器管理」で対象Nodeの「接続センサ」が「SEN66（検出済み）」になったら、「Logical IDを登録」を押します。
2. `sen66-001`などのIDを入力します。1〜48文字の英数字、`-`、`_`を使い、複数台では異なるIDを付けてください。
3. 「登録する」を押します。
4. Nodeカードに入力したLogical IDが表示されることを確認します。
5. 管理メニューの「表示設定」で「おすすめ」を選び、「保存してダッシュボードを確認」を押します。温度・湿度・CO₂濃度などの実測値が表示されることを確認してから、次の設置へ進みます。

「対応機能」の「SEN66対応」は接続済みという意味ではありません。接続の有無は「接続センサ」で見ます。

USB接続中のWi-Fi状態は「Wi-Fi設定済み」と表示されます。「登録済み」の表示は、設置場所で給電し直した後に確認します。

## 4. 設置して正常動作を確認する

1. 計測値を確認したら、AtomS3 LiteのUSBケーブルをGatewayから取り外し、**給電を止めます。**
2. ケースの蓋を仮置きし、ケーブルや固定具に当たらずに閉まることを確かめます。M3×8mmネジ6本で固定し、SEN66の吸気・排気口を塞がないようにします。
3. Gatewayと通信できる設置場所へ置き、USBケーブルを設置場所のUSB電源へ接続します。Nodeには常時給電します。
4. Dashboardの「管理メニュー → 機器管理」で、対象Nodeの「接続」が「オンライン」になることを確認します。
5. 同じカードにLogical IDと「登録済み」、「接続センサ: SEN66（検出済み）」が表示され、Dashboardの表示画面の計測値と「最終更新」が更新されることを確認します。

これでSEN66 Nodeの製作・登録・設置と、Dashboardでの計測確認が完了しました。**次へ：[Dashboardの使い方](dashboard.md)**で表示設定やデータの書き出しを確認してください。ほかの計測機器も追加する場合は、[センサ・計測機器を追加する](sensor-setup.md)を参照します。

値が出ない、Nodeがオンラインにならない場合は[トラブルシューティング](troubleshooting.md#センサや機器の値が更新されない)へ進みます。以下は、追加のNodeや登録内容の変更が必要になったときの手順です。

## 中継専用Nodeを追加する

[OMK Nodeの役割と設置](node-and-sensors.md)で設置場所を確認し、SEN66を接続していないAtomS3 Liteを用意します。同じファームウェアでBLE中継とNode間のMesh中継に対応するため、中継専用のファームウェアを選ぶ必要はありません。

1. [手順1](#1-gatewayへusb接続する)と[手順2](#2-dashboardからセットアップする)を行います。
2. 「セットアップ完了」を確認したらGatewayから取り外し、設置場所のUSB電源へ接続します。
3. 「機器管理」で「接続: オンライン」を確認します。中継専用NodeはLogical IDの登録が不要で、「Wi-Fi設定済み」「接続センサ: 未検出」の表示で使えます。

BLEセンサは[Dashboardの登録手順](dashboard.md#bleセンサを探索して登録する)に従い、初回はGatewayの近くで登録してから設置します。設置後も対象センサの「最終受信」が更新されることを確認してください。

## 登録済みのLogical IDを変更・解除する

「管理メニュー → 機器管理」のNodeカードで「Logical IDを変更」を押し、新しいIDを入力して「変更内容を登録」を押します。

「Logical ID登録を解除」を押すと、SEN66の登録を解除します。Wi-Fi設定や過去の計測データは残ります。再登録する場合は[手順3](#3-sen66を確認して登録する)へ戻ります。

## 既存Nodeを再セットアップする

別のGatewayへ移す場合や、microSD交換後に使い直す場合、接続先のOMK APを設定し直す場合は、この手順を使います。接続先のGatewayでは、[Gatewayセットアップ](gateway-setup.md)を完了しておきます。

Logical IDを登録済みのNodeが以前と同じWi-Fiへ接続できる場合は、再接続時にLogical IDが自動で復元されます。「機器管理」で「オンライン」と以前のLogical IDが表示され、計測値も届いていれば、再セットアップは不要です。

再セットアップすると、Node IDは変わりませんが、**Wi-Fiは接続先Gateway用に設定し直され、以前のLogical IDは解除されます。** SEN66を使う場合は、完了後に登録し直してください。

1. 対象のAtomS3 LiteだけをGatewayへUSB接続します。ほかの同種USB機器は一時的に取り外します。
2. Dashboardの「管理メニュー → 機器管理」で、「接続: USB接続」のNodeカードにある「OMK Nodeを再セットアップ」を押します。
3. 確認画面で、Wi-Fiが再設定されLogical IDが消去されることを読み、実行します。
4. USB接続と給電を維持し、「セットアップ完了」と表示されるまで待ちます。
5. SEN66を使う場合は[手順3](#3-sen66を確認して登録する)でLogical IDを登録し、[手順4](#4-設置して正常動作を確認する)で設置と計測を確認します。組み立て済みケースの蓋は外す必要はありません。中継だけに使う場合は[中継専用Nodeの設置確認](#中継専用nodeを追加する)へ進みます。

「OMK Nodeの再セットアップを再試行」が表示された場合は、そのボタンから再開します。完了しない場合は[Nodeセットアップのトラブルシューティング](troubleshooting.md#nodeセットアップを診断する)を参照してください。

## ファームウェアを更新する

現在、Dashboardには設定を保持したまま更新する専用ボタンはありません。「OMK Nodeを再セットアップ」では、上記のとおりWi-Fiの再設定とLogical IDの解除が行われます。

Wi-FiやLogical IDを保持する通常更新には、開発・保守用の実行環境が必要です。更新手順は[ファームウェアREADMEの通常更新](../../firmware/esp32/omk-node/README.md#factory-flashとpartition-table)を参照してください。

更新後は[手順4](#4-設置して正常動作を確認する)に沿って、Nodeが「オンライン」に戻り、同じLogical IDで計測値が表示されることを確認します。初回導入や再設定は、このページのDashboard手順を使ってください。

配布済みファームウェアに含まれる第三者ソフトウェアの許諾は[Third-party notices](../../firmware/esp32/omk-node/prebuilt/atom-s3-lite/THIRD_PARTY_NOTICES.md)を参照してください。バイナリを再配布する場合は同文書を同梱してください。

このページの設定・計測確認が完了したら、**次へ：[Dashboardの使い方](dashboard.md)**で日常の確認・表示設定・データ書き出しへ進みます。
