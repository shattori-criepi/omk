# AtomS3 LiteへのOMK Node導入

AtomS3 LiteをGatewayへUSB接続し、Dashboardからファームウェアの書き込みとWi-Fi設定を行います。SEN66を使う場合は、続けてセンサを登録します。

新品・未セットアップのAtomS3 Liteは、以下の手順で準備してください。使用済みNodeを別のGatewayへ移す場合や、microSD交換後に使い直す場合は、[既存Nodeの再設定](#既存nodeを再セットアップする)へ進みます。

## 1. 接続を準備する

- [Gatewayセットアップ](gateway-setup.md)でBLE Sensor Managerまで設定済みのGateway
- AtomS3 Lite
- データ通信に対応したUSBケーブル
- 設置場所でNodeへ給電するUSB電源

SEN66を使う場合は、先に[SEN66 Nodeの組み立て](sen66-node-assembly.md)に従って配線します。蓋は計測値を確認してから固定します。通信の中継だけに使う場合は、SEN66の接続は不要です。

対象のAtomS3 LiteをGatewayへUSB接続します。取り違えを防ぐため、ほかのAtomS3 Liteや同種の開発ボードは、セットアップ中だけGatewayのUSBから取り外してください。

## 2. Dashboardからセットアップする

1. Touch Display 2のDashboardで、右上の歯車から「管理メニュー → 機器管理」へ進みます。
2. 「接続: USB接続」と表示されたOMK Nodeのカードを見ます。新品・未セットアップでは「USB接続されたNode候補」と「OMK Nodeをセットアップ」が表示されます。既存のOMK Nodeで「OMK Nodeを再セットアップ」が表示されたら、[既存Nodeの再設定](#既存nodeを再セットアップする)へ進んでください。
3. 接続した実物が**未セットアップのAtomS3 Lite**であることを確かめ、「接続した機器が未セットアップのAtomS3 Liteであることを確認しました」にチェックを入れます。初回設定を途中から再開する場合、この確認欄は表示されないことがあります。
4. 「OMK Nodeをセットアップ」を押します。ファームウェアの書き込みとGatewayのWi-Fi設定が自動で行われます。
5. **USB接続と給電を維持したまま、「セットアップ完了」と表示されるまで待ちます。**

SEN66を使う場合は次の登録へ進みます。中継だけに使う場合は、[設置と動作確認](#4-設置して正常動作を確認する)へ進んでください。

「セットアップ失敗」と表示された場合やNodeが見つからない場合は、[Nodeセットアップのトラブルシューティング](troubleshooting.md#nodeセットアップを診断する)を参照してください。

## 3. SEN66を確認して登録する

Logical IDは、Nodeに接続したSEN66を区別する名前で、Dashboardや計測データで使います。中継だけに使うNodeでは登録不要です。

1. 「機器管理」で対象Nodeの「接続センサ」が「SEN66（検出済み）」になったら、「Logical IDを登録」を押します。
2. `sen66-001`などのIDを入力します。1〜48文字の英数字、`-`、`_`を使い、複数台では異なるIDを付けてください。
3. 「登録する」を押します。
4. Nodeカードに入力したLogical IDが表示されたら、次の設置へ進みます。

「対応機能」の「SEN66対応」は接続済みという意味ではありません。接続の有無は「接続センサ」で見ます。

USB接続中のWi-Fi状態は「Wi-Fi設定済み」と表示されます。「登録済み」の表示は、設置場所で給電し直した後に確認します。

## 4. 設置して正常動作を確認する

1. セットアップが完了したAtomS3 LiteをGatewayから取り外し、設置場所のUSB電源へ接続します。中継用のNodeも常時給電します。
2. Dashboardの「管理メニュー → 機器管理」で、対象Nodeの「接続」が「オンライン」になることを確認します。
3. SEN66を登録した場合は、同じカードにLogical IDと「登録済み」、「接続センサ: SEN66（検出済み）」が表示され、Dashboardの表示画面に温度・湿度・CO₂濃度などの値が出ることを確認します。

中継用Nodeは「Wi-Fi設定済み」で使えます。SEN66を接続していない場合の「接続センサ: 未検出」も正常です。

Nodeの準備ができたら、[Dashboardの使い方](dashboard.md)へ進み、BLEセンサの登録や表示設定を行います。値が出ない、Nodeがオンラインにならない場合は[トラブルシューティング](troubleshooting.md#センサや機器の値が更新されない)へ進みます。

## 登録済みのLogical IDを変更・解除する

「管理メニュー → 機器管理」のNodeカードで「Logical IDを変更」を押し、新しいIDを入力して「変更内容を登録」を押します。

「Logical ID登録を解除」を押すと、SEN66の登録を解除します。Wi-Fi設定や過去の計測データは残ります。再登録する場合は[手順3](#3-sen66を確認して登録する)へ戻ります。

## 既存Nodeを再セットアップする

別のGatewayへ移す場合や、接続先のWi-Fiを設定し直す場合も、この手順を使います。接続先のGatewayでは、[Gatewayセットアップ](gateway-setup.md)でBLE Sensor Managerまで設定しておきます。

Logical IDを登録済みのNodeが以前と同じWi-Fiへ接続できる場合は、再接続時にLogical IDが自動で復元されます。「機器管理」で「オンライン」と以前のLogical IDが表示され、計測値も届いていれば、再セットアップは不要です。

再セットアップすると、Node IDは変わりませんが、**Wi-Fiは接続先Gateway用に設定し直され、以前のLogical IDは解除されます。** SEN66を使う場合は、完了後に登録し直してください。

1. 対象のAtomS3 LiteだけをGatewayへUSB接続します。ほかの同種USB機器は一時的に取り外します。
2. Dashboardの「管理メニュー → 機器管理」で、「接続: USB接続」のNodeカードにある「OMK Nodeを再セットアップ」を押します。
3. 確認画面で、Wi-Fiが再設定されLogical IDが消去されることを読み、実行します。
4. USB接続と給電を維持し、「セットアップ完了」と表示されるまで待ちます。
5. SEN66を使う場合は[手順3](#3-sen66を確認して登録する)でLogical IDを登録し、[手順4](#4-設置して正常動作を確認する)で設置と計測を確認します。中継だけに使う場合は手順4へ進みます。

「OMK Nodeの再セットアップを再試行」が表示された場合は、そのボタンから再開します。完了しない場合は[Nodeセットアップのトラブルシューティング](troubleshooting.md#nodeセットアップを診断する)を参照してください。

## ファームウェアを更新する

現在、Dashboardには設定を保持したまま更新する専用ボタンはありません。「OMK Nodeを再セットアップ」では、上記のとおりWi-Fiの再設定とLogical IDの解除が行われます。

Wi-FiやLogical IDを保持する通常更新には、開発・保守用の実行環境が必要です。更新手順は[ファームウェアREADMEの通常更新](../../firmware/esp32/omk-node/README.md#factory-flashとpartition-table)を参照してください。

更新後は[手順4](#4-設置して正常動作を確認する)に沿って、Nodeが「オンライン」に戻り、同じLogical IDで計測値が表示されることを確認します。初回導入や再設定は、このページのDashboard手順を使ってください。
