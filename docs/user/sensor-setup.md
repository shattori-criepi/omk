# 3-1. センサ・計測機器を追加する

[「2-3. Gatewayセットアップ」](gateway-setup.md)でGatewayのセットアップが完了したら、計測する機器を追加します。初めて製作する場合は、次のSEN66 Nodeの手順を上から順に進めてください。

## この手順の前に

- Touch Display 2でDashboardを開けることを確認します。
- GatewayのBLE機能とBルートサービスは導入済みで、OMK APを有効にした状態にします。
- [「2-1. OMKのパーツ構成」](parts-list.md#sen66-nodeを使う場合)のSEN66 Node用部品を手元にそろえます。AtomS3 LiteとSEN66は、まだGatewayやUSB電源へ接続しません。

## まずSEN66 Nodeを1台追加する

SEN66 NodeはOMKの推奨センサ構成ですが、OMKの利用に必須ではありません。初めて製作する場合は、動作確認も兼ねて1台製作することを推奨します。

1. [「3-2. SEN66 Nodeの組み立て」](sen66-node-assembly.md)で、給電していないAtomS3 LiteへSEN66を配線し、ケースへ収めます。蓋は開けておきます。
2. [「3-3. SEN66 Nodeをセットアップする」](esp32-node-setup.md)で、GatewayへUSB接続してファームウェアとOMK APの設定を書き込みます。続けてSEN66のLogical IDを登録し、Dashboardで計測値を確認します。
3. 同じページの案内に従って蓋を固定し、設置場所のUSB電源へつなぎ直します。Dashboardの値と最終更新が更新されれば、SEN66での計測開始まで完了です。

次へ：[「3-2. SEN66 Nodeの組み立て」](sen66-node-assembly.md)へ進んでください。以下は、SEN66の計測を確認した後で、ほかの機器を追加するときに使います。

## SwitchBot等のBLEセンサを追加する

BLEセンサはGateway自身で直接受信できます。まず対象センサの電源を入れてGatewayの近くへ置き、[「4-1. Dashboardの使い方」](dashboard.md#bleセンサを探索して登録する)に従って探索・登録します。対応機種は[「1-3. 対応センサ・機器と取得データ」](supported-devices.md#switchbot対応機器)で確認できます。

登録後は設置場所へ戻し、「機器管理」で「最終受信」が更新されることを確認します。Gatewayから遠くて直接受信できないときは、近くのOMK Nodeが代わりにBLEの電波を受信し、データをGatewayへ送る「BLE中継」を使えます。SEN66 Nodeもこの中継を兼ねられます。

**初回登録はGatewayの近くで行ってください。** OMK Node経由でのみ受信している未登録のBLEセンサは探索候補に表示されません。

## Bルートでスマートメーターを追加する

Gateway側のBルートサービスは、Gatewayセットアップで導入済みです。電力会社から発行されたBルートIDとパスワードを用意し、アダプタの設定状況に応じて進めます。

### Gatewayセットアップでアダプタを設定済みの場合

RS-WSUHA-Pを接続したまま[「4-1. Dashboardの使い方」](dashboard.md#bルートを設定する)に従い、BルートID・パスワードを入力して「保存して接続」を押します。セットアップスクリプトの再実行は不要です。「接続状態」が「接続済み」になり、Dashboardに電力データが表示されることを確認します。

### 後からアダプタを追加する場合

Gatewayセットアップをアダプタ未接続で完了した場合、または接続していてもシリアルポートの設定を済ませていない場合は、次を行います。

1. RS-WSUHA-PをGatewayのUSBへ接続します。接続済みのAtomS3 LiteはGatewayから取り外し、設置場所のUSB電源へ戻します。ほかのUSBシリアル機器も一時的に取り外し、設定対象を取り違えない状態にします。Onyxは外部通信に使うため接続したままにします。
2. [「2-3. Gatewayセットアップ」](gateway-setup.md#ap切替後の操作方法)のAP切替後の操作方法でターミナルを開きます。パッケージを取得するため、Gateway自身がOnyx経由でインターネットへ接続できることを確認します。
3. Gateway上で次を実行します。

   ```bash
   cd ~/projects/omk
   ./scripts/setup-broute-meter.sh
   ```

4. `Use this FT230X serial adapter as RS-WSUHA-P? ... [y/N]`と表示されたら、接続した実物がRS-WSUHA-Pであることを確認して`y`を入力します。既に接続先を設定済みの場合、この確認は表示されません。
5. 完了まで待ちます。スクリプトがRS-WSUHA-Pの抜き差しを求めた場合は、そのアダプタだけを抜き、数秒待って同じUSB端子へ接続し直します。OnyxやGatewayの電源は外しません。
6. [「4-1. Dashboardの使い方」](dashboard.md#bルートを設定する)に従い、BルートID・パスワードを入力して「保存して接続」を押します。
7. 「接続状態」が「接続済み」になり、Dashboardに電力データが表示されることを確認します。

セットアップスクリプトはBルートIDとパスワードを尋ねません。認証情報はDashboardで入力します。スクリプトがエラーで停止した場合や計測できない場合は、[「5-3. トラブルシューティング」](troubleshooting.md#bルートのデータを取得できない)を参照してください。
