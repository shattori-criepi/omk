# Bルートでスマートメーターを追加する

Gatewayセットアップで導入したBルートサービスを使い、低圧スマートメーターの計測を始めます。Touch Display 2でDashboardを操作できることを確認し、RS-WSUHA-Pと、電力会社から発行されたBルートID・パスワードを用意してください。

## 1. アダプタの設定を確認する

Gatewayセットアップ時にRS-WSUHA-Pを接続し、実物確認に`y`と答えてスクリプトが完了していれば、アダプタは設定済みです。接続を維持したまま手順2へ進みます。スクリプトの再実行は不要です。

### 後からアダプタを追加する場合

アダプタ未接続でGatewayセットアップを完了した場合や、シリアルポートの設定を済ませていない場合は、次を行います。

1. RS-WSUHA-PをGatewayのUSBへ接続します。接続済みのAtomS3 Liteは設置場所のUSB電源へ戻し、ほかのUSBシリアル機器も一時的に取り外します。Onyxは外部通信のため接続したままにします。
2. GatewayのUSBキーボードで`Ctrl+Alt+T`を押し、ターミナルを開きます。パッケージ取得のため、Gateway自身がOnyx経由でインターネットへ接続できることを確認します。
3. 次を実行します。

   ```bash
   cd ~/projects/omk
   ./scripts/setup-broute-meter.sh
   ```

4. `Use this FT230X serial adapter as RS-WSUHA-P? ... [y/N]`と表示されたら、接続した実物がRS-WSUHA-Pであることを確認して`y`を入力します。接続先を設定済みの場合、この確認は表示されません。
5. スクリプトの完了まで待ちます。RS-WSUHA-Pの抜き差しを求められた場合は、そのアダプタだけを抜き、数秒待って同じUSB端子へ接続し直します。OnyxやGatewayの電源は外しません。

スクリプトは認証情報を尋ねません。BルートID・パスワードの未登録により、サービスが起動しない場合があります。スクリプトがエラーで停止した場合は[「トラブルシューティング」](troubleshooting.md#パッケージやomkのダウンロードが失敗する)を参照してください。

## 2. BルートID・パスワードを登録する

1. Touch Display 2でDashboardの「管理メニュー → Bルート設定」を開きます。
2. 電力会社から発行された情報を「BルートID」「パスワード」に入力します。
3. 「保存して接続」を押します。
4. 画面上部の「接続状態」が「接続済み」になることを確認します。

## 3. 計測を確認する

Dashboardでは現在の電力に加え、本日の買電量・売電量も表示できます。30分周期のBルート積算値・30分値は、最後に受信してから45分以内が`normal`、45分超～90分以内が`delayed`、90分超が`unavailable`です。

Dashboardの表示設定で「おすすめ」を選び、表示画面で電力データと「最終更新」が更新されれば追加完了です。接続できない場合や値が届かない場合は[「トラブルシューティング」](troubleshooting.md#bルートのデータを取得できない)を参照してください。
