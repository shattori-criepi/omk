# 1-2. 対応センサ・機器と取得データ

OMKで使える機器、取得できる値、接続方法の一覧です。「対応」は表に記載したデータを取得する機能があることを示し、製品の全機能や、すべての個体・ファームウェアでの動作確認を意味しません。対応範囲はこのページに記載している機器・データに限ります。計測値は設置環境や機器の状態により取得できないことがあります。

## 一覧

OMKで一般的に利用する機器カテゴリと、主な計測項目です。

| 機器・センサ | 接続方法 | 取得できる値・状態 | 対応上の注意 |
| --- | --- | --- | --- |
| 低圧スマートメーター（Bルート） | RS-WSUHA-PをGatewayへUSB接続し、スマートメーターから無線で受信 | 系統の瞬時電力（W）、買電・売電の積算電力量（kWh）、30分ごとの買電量・売電量（kWh） | 売電の積算電力量・30分ごとの売電量は、スマートメーターが逆方向の計量に対応している場合に取得します。瞬時電力は買電時が正、売電時が負です。 |
| [Sensirion SEN66（公式製品情報）](https://sensirion.com/jp/products/catalog/SEN66) | SEN66をOMK Nodeへ接続し、NodeからGatewayへ送信 | 温度（℃）、相対湿度（%）、CO₂濃度（ppm）、PM1.0・PM2.5・PM4.0・PM10濃度（µg/m³）、VOC Index、NOx Index | SEN66を接続したAtomS3 Liteを使います。詳細な仕様やVOC Index・NOx Indexの説明は、公式製品情報と同ページ掲載のデータシートを参照してください。 |
| SwitchBot BLEセンサ | BLE | 温湿度、CO₂濃度、人感・在不在、開閉、消費電力など（機種による） | 対応機種の詳細は[次節](#switchbot対応機器)を参照してください。 |

## SwitchBot対応機器

以下の機器がBLEで送信する計測値や状態を、Gatewayで受信します。OMKで計測値を受信するために、GatewayとのBluetoothペアリングやSwitchBotハブとの接続は必要ありません。同型・類似製品でも、ファームウェアや送信内容の違いにより利用できない場合があります。

| 機器・センサ | 接続方法 | 取得できる値・状態 | 対応上の注意 |
| --- | --- | --- | --- |
| SwitchBot 温湿度計（Meter、Meter Plus） | BLE | 温度（℃）、相対湿度（%） | — |
| SwitchBot CO2センサー（Meter Pro CO2） | BLE | 温度（℃）、相対湿度（%）、CO₂濃度（ppm） | — |
| SwitchBot 人感センサー | BLE | 人感状態 | 状態変化時のほか、定期的に送信される状態も取得します。 |
| SwitchBot 人感センサーPro | BLE | 人感／在不在状態、バッテリー残量、照度レベル（0～15の16段階） | バッテリー残量は取得できない場合があります。 |
| SwitchBot 開閉センサー | BLE | 開閉状態 | 状態変化時のほか、定期的に送信される状態も取得します。 |
| SwitchBot プラグミニ | BLE | 消費電力（W）、ON／OFF状態 | — |
| SwitchBot 防水温湿度計 | BLE | 温度（℃）、相対湿度（%） | — |
