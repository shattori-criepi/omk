# 4-1. Dashboardの使い方

Dashboardで、計測値と機器の状態を確認し、表示設定や保存済みデータの書き出しを行います。

このページでは、Gatewayに取り付けたTouch Display 2で操作します。Gatewayを起動するとDashboardが表示されます。右上の歯車を押すと、管理メニューを開きます。

## 表示画面

現在の計測値・状態と「最終更新」の時刻を表示します。

計測値をまとめて配置する枠を「ブロック」と呼びます。値の状態は、最後にデータを受信してからの時間で変わります。

| 状態 | 最後に受信してからの時間 |
| --- | --- |
| `normal` | 6分以内 |
| `delayed` | 6分超～10分以内 |
| `unavailable` | 10分超 |

一度も取得できていない値も`unavailable`です。`delayed`では受信済みの値を表示し、`unavailable`では現在値を表示できません。

ブロックの状態は、その中に表示する値から決まります。

- 全て`normal`：`normal`
- `delayed`を含む：`delayed`
- `normal`と`unavailable`が混在：`delayed`
- 全て`unavailable`：`unavailable`

`delayed`のブロックには「遅延」、`unavailable`のブロックには「取得不可」と表示されます。画面上部は、現在表示しているブロックのうち最も悪い状態（`unavailable`、`delayed`、`normal`の順）を表示します。登録済みの全センサを対象にするわけではありません。時計モードでは、時計と一緒に表示している計測値を対象にします。

値が更新されない場合は、[「トラブルシューティング」](troubleshooting.md#センサや機器の値が更新されない)へ進んでください。過去の計測値は、[データ書き出し](#データを書き出す)で取得します。Dashboardには履歴や時系列グラフの表示機能はありません。

## 管理メニュー

- **表示設定**：[表示モードや表示する値を変更します](#表示モードを変更する)。
- **機器管理**：[SEN66 Nodeの接続状態を確認します](#機器の状態を確認する)。
- **Bルート設定**：スマートメーター計測を利用するときの認証情報と接続状態を扱います。SEN66の計測では操作不要です。
- **OMKアクセスポイント参照**：[OMK APのSSID・パスワード・QRコードを表示します](#omk-apの接続情報を見る)。
- **システム操作**：[Gatewayを再起動・シャットダウンします](#gatewayを再起動シャットダウンする)。
- **データ書き出し**：[保存済みデータをUSBメモリへ書き出します](#データを書き出す)。

## 表示モードを変更する

管理メニューの「表示設定」を開き、モードを選びます。

| モード | 表示内容・設定 |
| --- | --- |
| **おすすめ** | 利用できる主要な計測項目を自動で表示します。項目の設定は不要です。 |
| **カスタム** | 表示する値、順序、サイズなどを自分で設定します。 |
| **時計** | 日付・時刻を大きく表示し、利用できる電力・環境情報を自動で添えます。項目の設定は不要で、センサなしでも時計を表示できます。 |
| **デモ** | 展示・動作確認用の表示です。模擬データを含み、利用できる実測値も表示します。センサの登録なしでも試せます。 |

「保存してダッシュボードを確認」を押すと、表示画面へ戻ります。

カスタム表示は次の手順で設定します。

1. 「カスタム」を選び、「表示可能なデータ」で「このデータでブロックを追加」を押します。
2. 「表示中ブロック」で「サイズ」と「表示形式」を選びます。小サイズの表示形式は自動です。
3. 表示したい値にチェックを入れ、「主表示」で中心となる値を選びます。
4. 「上へ」「下へ」で順序を変えます。表示から外すブロックは「削除」を押します。
5. 「保存してダッシュボードを確認」を押します。

「表示領域がいっぱいです」と表示されたら、既存ブロックのサイズを小さくするか削除してから追加します。

デモ画面では、値に付く「実測」「模擬」でデータを区別できます。模擬データは計測データとして保存・送信されません。通常の表示へ戻すには、「表示設定」で「おすすめ」「カスタム」「時計」のいずれかを選びます。

## 機器の状態を確認する

管理メニューの「機器管理」を開き、SEN66 Nodeのカードを確認します。

- 設置場所で給電しているNodeの「接続」が「オンライン」になっている。
- 登録したLogical IDと「登録済み」が表示されている。
- 「接続センサ」が「SEN66（検出済み）」になっている。

表示画面へ戻り、計測値と「最終更新」が更新されることを確認します。更新されない場合は[「トラブルシューティング」](troubleshooting.md#センサや機器の値が更新されない)を参照してください。

## OMK APの接続情報を見る

管理メニューの「OMKアクセスポイント参照」を開くと、SSIDが表示されます。「表示」を押すと、Wi-Fiパスワードと接続用QRコードも表示されます。OMK APはGateway・Node・管理端末を結ぶローカルネットワークです。外部通信が必要なGateway自身はOnyxを使います。

## Gatewayを再起動・シャットダウンする

管理メニューの「システム操作」で「再起動」または「シャットダウン」を選び、確認画面の「実行」を押します。この間は計測も停止します。シャットダウン後は、電源を入れ直すまで利用できません。

## データを書き出す

保存済みデータをCSVにまとめ、ZIPとしてUSBメモリへ書き出します。

1. FAT32またはexFATのUSBメモリをGatewayへ1台だけ接続します。長期間・大容量の書き出しにはexFATを推奨します。
2. 管理メニューの「データ書き出し」を開きます。
3. 「開始日」「終了日」を選びます。「今日」「過去7日」「過去30日」「今月」でも期間を指定できます。
4. 「データ」で書き出す項目にチェックを入れます。「すべて選択」でまとめて選べます。
5. 「USBへ書き出す」を押します。**書き出し中はUSBメモリを取り外さないでください。**
6. 「書き出しが完了しました」と「USBメモリを取り外せます」が表示されたら、USBメモリを取り外します。
7. USBメモリをPCへ接続し、`OMK`フォルダー内のZIPを展開してCSVを開きます。

直近のデータは、保存処理が完了するまで書き出しに含まれない場合があります。

「USBメモリを安全に取り外せません」と表示されたら、USBメモリを抜かずに[「トラブルシューティング」](troubleshooting.md#usbメモリを安全に取り外せませんと表示される)へ進みます。USBメモリを認識しない場合や書き出せない場合も、[「トラブルシューティング」](troubleshooting.md#usbメモリへデータを書き出せない)を参照してください。

## 初回導入の完了確認

登録したSEN66などの実測値と「最終更新」の時刻が更新されていれば、計測を開始できています。表示設定で「おすすめ」を選ぶと、利用できる主要な計測値を表示します。デモの模擬値は実測の確認に使わないでください。

ここまでで、推奨構成のOMKの製作・セットアップとSEN66による計測確認は完了です。BLEセンサやBルートの追加、計測範囲の拡張、ソフトウェアの更新などを行う場合は、[「OMK — おうちモニタキット」](../../README.md#omkの製作方法)（README）の「OMKの製作方法」へ戻り、「必要に応じて行う作業」から目的に合う項目を参照してください。
