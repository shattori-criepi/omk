# Dashboardの使い方

Dashboardでは、現在の計測値や機器の状態を見たり、表示方法の変更、センサの登録・設定、データの書き出しを行ったりできます。[Gatewayセットアップ](gateway-setup.md)を完了してから使用します。

Gatewayを起動するとTouch Display 2にDashboardが表示されます。右上の歯車を押すと、管理メニューを開きます。

## 表示画面

現在の計測値・状態と「最終更新」の時刻を表示します。Bルートを使用している場合は、現在の電力に加え、本日の買電量・売電量も表示できます。

計測値をまとめて配置する枠を「ブロック」と呼びます。値の状態は、最後にデータを受信してからの時間で変わります。

| 状態 | 通常の計測値 | 30分周期のBルート積算値・30分値 |
| --- | --- | --- |
| `normal` | 6分以内 | 45分以内 |
| `delayed` | 6分超～10分以内 | 45分超～90分以内 |
| `unavailable` | 10分超 | 90分超 |

一度も取得できていない値も`unavailable`です。`delayed`では受信済みの値を表示し、`unavailable`では現在値を表示できません。

ブロックの状態は、その中に表示する値から決まります。

- 全て`normal`：`normal`
- `delayed`を含む：`delayed`
- `normal`と`unavailable`が混在：`delayed`
- 全て`unavailable`：`unavailable`

`delayed`のブロックには「遅延」、`unavailable`のブロックには「取得不可」と表示されます。画面上部は、現在表示しているブロックのうち最も悪い状態（`unavailable`、`delayed`、`normal`の順）を表示します。登録済みの全センサを対象にするわけではありません。時計モードでは、時計と一緒に表示している計測値を対象にします。

値が更新されない場合は、[センサや機器の対処方法](troubleshooting.md#センサや機器の値が更新されない)へ進んでください。過去の計測値は、[データ書き出し](#データを書き出す)で取得します。Dashboardには履歴や時系列グラフの表示機能はありません。

## 管理メニュー

- **表示設定**：[表示モードや表示する値を変更します](#表示モードを変更する)。
- **機器管理**：[OMK NodeとSEN66](esp32-node-setup.md)、[BLEセンサ](#bleセンサを探索して登録する)を登録・編集します。
- **Bルート設定**：[BルートID・パスワードを入力し、接続状態を見ます](#bルートを設定する)。
- **OMKアクセスポイント参照**：[OMK APのSSID・パスワード・QRコードを表示します](#omk-apの接続情報を見る)。
- **システム操作**：[Gatewayを再起動・シャットダウンします](#gatewayを再起動シャットダウンする)。
- **データ書き出し**：[保存済みデータをUSBメモリへ書き出します](#データを書き出す)。

## 表示モードを変更する

管理メニューの「表示設定」を開き、モードを選びます。

| モード | 表示内容・設定 |
| --- | --- |
| **おすすめ** | 利用できる主要な計測項目を自動で表示します。項目の設定は不要です。 |
| **カスタム** | 表示する値、順序、サイズなどを自分で設定します。 |
| **時計** | 日付・時刻を大きく表示し、利用できる電力・環境情報を自動で添えます。項目の設定は不要で、センサなしでも時計を表示できます。 |
| **デモ** | 展示・動作確認用の表示です。模擬データを含み、利用できる実測値も表示します。センサの登録なしでも試せます。 |

「保存してダッシュボードを確認」を押すと、表示画面へ戻ります。

カスタム表示は次の手順で設定します。

1. 「カスタム」を選び、「表示可能なデータ」で「このデータでブロックを追加」を押します。
2. 「表示中ブロック」で「サイズ」と「表示形式」を選びます。小サイズの表示形式は自動です。
3. 表示したい値にチェックを入れ、「主表示」で中心となる値を選びます。
4. 「上へ」「下へ」で順序を変えます。表示から外すブロックは「削除」を押します。
5. 「保存してダッシュボードを確認」を押します。

「表示領域がいっぱいです」と表示されたら、既存ブロックのサイズを小さくするか削除してから追加します。

デモ画面では、値に付く「実測」「模擬」でデータを区別できます。模擬データは計測データとして保存・送信されません。通常の表示へ戻すには、「表示設定」で「おすすめ」「カスタム」「時計」のいずれかを選びます。

## BLEセンサを探索して登録する

BLEセンサは、Gatewayで直接受信する方法と、OMK Node経由で受信する方法があります。**初回登録時は、センサをGatewayの近くへ置いてください。** OMK Node経由でのみ受信している未登録センサは、探索候補に表示されません。対応機種は[対応センサ・機器と取得データ](supported-devices.md#switchbot対応機器)を参照してください。

1. 管理メニューの「機器管理」を開き、「センサを追加」を押します。
2. 対象のセンサの「このセンサを登録」を押します。
3. 登録画面で次の項目を入力します。

   | 項目 | 入力内容 |
   | --- | --- |
   | OMK センサID | センサを区別するID。自動入力された候補をそのまま使えます。 |
   | 表示名 | Dashboardに表示する名前。例：リビング |
   | 設置場所（任意） | 設置位置のメモ |

4. 「登録する」を押します。
5. 「登録済みセンサ」に対象が表示され、「最終受信」が更新され、状態が「正常」になれば登録・受信を確認できます。

登録後は設置場所へ戻し、GatewayまたはOMK Node経由で受信します。候補に出ない場合は[センサが見つからない場合の対処](troubleshooting.md#センサや機器の値が更新されない)を参照してください。

### 「候補（未確認）」と表示された場合

防水温湿度計や人感センサーなどは、機種を自動判定できず「候補（未確認）」と表示されることがあります。実物の機種と候補名を照合し、カードの「未確認プレビュー」を見ます。温湿度計を手で温めたときに温度が上がるか、人感センサーの前で動いたときに検知状態が変わるかで、対象の機器かを確かめます。

対象の機器だと分かったら、機種名の付いた「…と確認して登録」を押します。登録画面の実物確認欄にチェックを入れ、上と同じ項目を入力して「登録する」を押します。「未対応のSwitchBot機器」は登録できません。

### 登録内容を変更・削除する

「登録済みセンサ」の「編集」でID、表示名、設置場所を変更し、「保存する」を押します。「このセンサを有効にする」のチェックで有効・無効を切り替えられます。

「センサ登録を削除」は登録情報を削除する操作です。過去の計測データは残ります。

## Bルートを設定する

[Bルートのセットアップ](gateway-setup.md#8-bルートを使用する場合は設定する)が完了したら、次の操作でスマートメーターに接続します。

1. 管理メニューの「Bルート設定」を開きます。
2. 電力会社から発行された情報を「BルートID」「パスワード」に入力します。
3. 「保存して接続」を押します。
4. 画面上部の「接続状態」が「接続済み」になったら、Dashboardの表示画面で電力データを見ます。

接続できない場合は[Bルートの対処方法](troubleshooting.md#bルートのデータを取得できない)を参照してください。

## OMK APの接続情報を見る

管理メニューの「OMKアクセスポイント参照」を開くと、SSIDが表示されます。「表示」を押すと、Wi-Fiパスワードと接続用QRコードも表示されます。接続する端末でSSID・パスワードを入力するか、QRコードを読み取ります。OMK APはインターネット接続用ではありません。

## Gatewayを再起動・シャットダウンする

管理メニューの「システム操作」で「再起動」または「シャットダウン」を選び、確認画面の「実行」を押します。この間は計測も停止します。シャットダウン後は、電源を入れ直すまで利用できません。

## データを書き出す

保存済みデータをCSVにまとめ、ZIPとしてUSBメモリへ書き出します。

1. FAT32またはexFATのUSBメモリをGatewayへ1台だけ接続します。長期間・大容量の書き出しにはexFATを推奨します。
2. 管理メニューの「データ書き出し」を開きます。
3. 「開始日」「終了日」を選びます。「今日」「過去7日」「過去30日」「今月」でも期間を指定できます。
4. 「データ」で書き出す項目にチェックを入れます。「すべて選択」でまとめて選べます。
5. 「USBへ書き出す」を押します。**書き出し中はUSBメモリを取り外さないでください。**
6. 「書き出しが完了しました」と「USBメモリを取り外せます」が表示されたら、USBメモリを取り外します。
7. USBメモリをPCへ接続し、`OMK`フォルダー内のZIPを展開してCSVを開きます。

直近のデータは、保存処理が完了するまで書き出しに含まれない場合があります。

「USBメモリを安全に取り外せません」と表示されたら、USBメモリを抜かずに[安全に取り外せない場合の対処](troubleshooting.md#usbメモリを安全に取り外せませんと表示される)へ進みます。USBメモリを認識しない場合や書き出せない場合も、[USB書き出しのトラブルシューティング](troubleshooting.md#usbメモリへデータを書き出せない)を参照してください。

## PCやタブレット等からDashboardを使う場合

Touch Display 2の[「OMKアクセスポイント参照」](#omk-apの接続情報を見る)でSSIDとパスワードを表示し、PCやタブレット等をそのWi-Fiへ接続します。ブラウザで`http://192.168.50.1:8000/`を開いてください。OMK APはインターネット接続用ではありません。
