# BLEセンサを追加する

推奨構成の製作が完了した後で、SwitchBotなどのBLEセンサをGatewayへ追加する手順です。GatewayのBLE Sensor Managerを導入済みで、Touch Display 2からDashboardを操作できることを確認してください。

## 用意するセンサ

計測したい内容に合わせて選びます。次の製品は参考例です。

| 用途 | 参考製品 |
| --- | --- |
| 人感・在不在 | [SwitchBot 人感センサーPro](https://www.switchbot.jp/products/switchbot-presence-sensor) |
| ドア・窓の開閉 | [SwitchBot 開閉センサー](https://www.switchbot.jp/products/switchbot-contact-sensor) |
| 消費電力・電源状態 | [SwitchBot プラグミニ（JP）](https://www.switchbot.jp/products/switchbot-plug-mini) |
| 温度・湿度 | [SwitchBot 温湿度計](https://www.switchbot.jp/products/switchbot-meter) |
| CO₂濃度・温度・湿度 | [SwitchBot CO2センサー（Meter Pro CO2）](https://www.switchbot.jp/products/switchbot-co2-meter) |
| 温度・湿度（防水タイプ） | [SwitchBot 防水温湿度計](https://www.switchbot.jp/products/switchbot-indoor-outdoor-meter) |

## この手順の前に

- 対応機種を[「1-2. 対応センサ・機器と取得データ」](supported-devices.md#switchbot対応機器)で確認します。
- センサの電源を入れ、Gatewayの近くへ置きます。BluetoothペアリングやSwitchBotハブとの接続は不要です。

## BLEセンサを探索して登録する

1. 管理メニューの「機器管理」を開き、「センサを追加」を押します。
2. 対象のセンサの「このセンサを登録」を押します。
3. 登録画面で次の項目を入力します。

   | 項目 | 入力内容 |
   | --- | --- |
   | OMK センサID | センサを区別するID。自動入力された候補をそのまま使えます。 |
   | 表示名 | Dashboardに表示する名前。例：リビング |
   | 設置場所（任意） | 設置位置のメモ |

4. 「登録する」を押します。
5. 「登録済みセンサ」に対象が表示され、「最終受信」が更新され、状態が「正常」になれば登録・受信を確認できます。

登録後は設置場所へ戻し、「最終受信」が更新されることを確認します。候補に出ない場合は[「トラブルシューティング」](troubleshooting.md#センサや機器の値が更新されない)を参照してください。

### 「候補（未確認）」と表示された場合

これは受信した機器の機種をまだ確定できていないという表示です。製品自体の実機試験の有無を示すものではありません。参考値は登録確認用で、登録前の計測データとしては保存・送信されません。

防水温湿度計や人感センサーなどは、機種を自動判定できず「候補（未確認）」と表示されることがあります。実物の機種と候補名を照合し、カードの「未確認プレビュー」を見ます。温湿度計を手で温めたときに温度が上がるか、人感センサーの前で動いたときに検知状態が変わるかで、対象の機器かを確かめます。

対象の機器だと分かったら、機種名の付いた「…と確認して登録」を押します。登録画面の実物確認欄にチェックを入れ、上と同じ項目を入力して「登録する」を押します。「未対応のSwitchBot機器」は登録できません。

### 登録内容を変更・削除する

「登録済みセンサ」の「編集」でID、表示名、設置場所を変更し、「保存する」を押します。「このセンサを有効にする」のチェックで有効・無効を切り替えられます。

「センサ登録を削除」は登録情報を削除する操作です。過去の計測データは残ります。

## 追加完了の確認

設置場所でセンサの「最終受信」が更新され、状態が「正常」になれば追加完了です。Dashboardの表示設定で「おすすめ」を選び、計測値を確認します。
