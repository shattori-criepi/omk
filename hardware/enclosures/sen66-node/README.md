# SEN66 Node試作筐体

このディレクトリには、AtomS3 LiteとSEN66を主な対象とするSEN66 Node用3Dプリント試作筐体のSTLを格納しています。

## 格納済みSTL

- [sen66-node-body.stl](sen66-node-body.stl): 本体
- [sen66-node-lid.stl](sen66-node-lid.stl): 蓋
- [sen66-node-cable-jig.stl](sen66-node-cable-jig.stl): USB-Cケーブルの引張による抜けを軽減するための固定治具

現時点では試作筐体です。SEN66の吸気・排気を塞がず、センサの設置向きと通気を考慮して使用してください。

組み立てにはM3×8mmネジを6本使用します。3Dプリントしたネジ穴にはM3タップ加工が必要です。印刷方向、材料、積層条件は未確定のため、根拠のない推奨値は記載しません。筐体成果物はこのディレクトリで管理します。

ケーブル固定治具は、現在Anker Zolo USB-C & USB-A ケーブルでのみ適合を確認しています。USB-Cプラグのモールド形状が異なるケーブルには適合しない可能性があります。

利用者向けの組み立て概要は[SEN66 Nodeの組み立て](../../../docs/user/sen66-node-assembly.md)を参照してください。
