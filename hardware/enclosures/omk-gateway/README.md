# OMK Gateway筐体

このディレクトリには、SORACOM OnyxをOMK Gatewayへ省スペースに取り付けるための3Dプリント部品を格納しています。

## 用途

回転式USB-A変換コネクタを使ってOnyxの向きを90度変更し、この部品でOnyxを固定する参考構成です。Onyxの利用や設定に必須ではありません。

## 使用する参考部品

- [SORACOM Onyx LTE USBドングル](https://soracom.jp/store/7326/)
- [エスエスエーサービス USB A変換コネクタ（Aメス/Aオス 回転式）](https://www.amazon.co.jp/dp/B00OPYC7DK)

## STL

- [onyx-usb-holder.stl](onyx-usb-holder.stl): Onyx固定用部品

## 注意

- この部品は試作ハードウェア成果物です。
- Raspberry Pi、ケース、USBコネクタなどの個体差を確認して使用してください。
- USB端子へ無理な力を加えないでください。
- Onyxの放熱や通信を妨げないよう、実際の設置状態を確認してください。
